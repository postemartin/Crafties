    Terms and sizing

      Before you start

      Finished bracelet: about 7 in / 18 cm around, with tie ends for adjusting.
      Cut length: six yarn strands, each 24 in / 60 cm long.
      Choose 3 colors, using 2 strands of each color, or use 6 strands of one color.

      Pattern instructions

        Finishing

          Beginner help

            💜 Kindness twist: Give each color a wish: courage, calm, joy, patience, kindness, or hope.

            Pattern note

            This is now a true printable yarn bracelet pattern. Keep the braid snug but soft, check the wrist size before trimming, and remove the bracelet for sleep, sports, water, or any time it catches.
